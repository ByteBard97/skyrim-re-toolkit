Contributing

We're not looking for novel RE research. We're looking for reliable engineering on top of what the community — CommonLibSSE-NG, meh321's Address Library, SKSE — has already reverse-engineered.

Where help is most useful right now

type-importer

If you know libclang, Ghidra's Java API, or MSVC ABI quirks, we need you. See the deferred patches for the remaining known root causes.

symbol-archive

If you can write GitHub Actions workflows or validate struct layouts against live binaries, we need you.

runtime-harness

If you've built SKSE plugins and know your way around AIProcess, hkpCharacterProxy, or BGSSaveLoadManager, we need you.

Ground rules — binding, not suggestions

  • No console exploits, no DRM circumvention, no redistribution of game binaries, PDBs, or copyrighted assets.
  • Every type or offset must be derivable from public community sources (CommonLibSSE-NG, Address Library, RTTI) — not from acquiring or dumping Bethesda's own build artifacts.
  • Don't invent offsets, struct layouts, or version numbers. Pull them from CommonLibSSE-NG or the Address Library, or open an issue if the source isn't available to you.
  • Don't commit generated type archives (.gdt/.til) or built binaries — these are CI-published artifacts, not source.

Platform split matters

type-importer and symbol-archive are Linux-native (Ghidra, libclang, GitHub Actions ubuntu-latest all work fine). runtime-harness is Windows + MSVC only, no exceptions — see the repo's project notes before assuming a change there can be tested on Linux.

Before opening a PR touching the parser

If you're touching type-importer's parser (patches under type-importer/patches/), follow the existing methodology:

  1. Root-cause with a minimal reproduction before writing a fix.
  2. Verify with a full sweep (generate_gdt.sh + coverage_report.py + check_regression.py) against the committed baseline.
  3. Write up the patch following the numbering/format already established in type-importer/patches/*.md.
Zero regressions required. A fix that unmasks a pre-existing bug is fine — but document it; never merge a net-negative patch.

Licensing

The toolkit code itself is MIT. Generated .gdt/.til archives are derived from CommonLibSSE-NG headers and inherit its GPL-3.0 (+ modding exception) license — don't relicense generated archives.
